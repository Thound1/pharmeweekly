파메어스 업무보드 v1.5.2 · PAMECON Shimeji+ 패치

기준
- v1.5.1 PAMECON 완성도 개선판을 기준으로 제작
- 이미지/프레임 파일은 변경하지 않음
- Google Sheets 저장/동시편집/입력 보호 로직은 그대로 유지

추가 기능
1. 수면 동작
   - 잠들기 진입 후 실제로 누워 있는 시간을 5~16초 사이에서 랜덤 설정
   - 수면 중 마지막 두 프레임을 천천히 교차해 미세한 호흡 느낌 추가
   - 랜덤 시간이 끝나면 역순으로 자연스럽게 깨어남

2. 점프 동작
   - 한 번 점프가 선택될 때 1~5회를 랜덤 반복
   - PE 로고 5회 클릭으로 반응할 때도 1~5회 랜덤 점프

3. 드래그 / 쓰로잉
   - 파메콘을 마우스 왼쪽 버튼으로 잡아서 이동 가능
   - 빠르게 놓으면 드래그 속도와 방향을 계산하여 실제로 던져짐
   - 공중에서는 기존 점프 프레임을 사용
   - 중력, 바닥 착지, 좌우 벽 반동 적용
   - 바닥에 안정적으로 착지한 뒤 다시 대기/걷기 상태로 복귀
   - 입력창에 포커스가 있어도 파메콘을 잡을 때 preventDefault 처리하여
     가능한 기존 입력 포커스를 유지하도록 구성

4. 파메콘 복제
   - 파메콘 우클릭 메뉴에 '파메콘 복사하기' 추가
   - 현재 마리 수 표시
   - 최대 5마리까지 생성 가능
   - 각 파메콘은 독립적으로 걷기/대기/점프/기지개/수면 동작 수행
   - 각각 개별 드래그/던지기/숨김 가능

5. 우클릭 메뉴
   - 파메콘 복사하기
   - 이 파메콘 숨기기
   - 5마리 도달 시 복사 메뉴 자동 비활성화

교체 대상
- app.js
- styles.css
- index.html

assets/pamecon, config.js, Google Sheet, seed-data.js, xlsx-export.js는 변경할 필요 없습니다.

검증
- PE 5회 클릭 → 등장
- 우클릭 복제 → 5마리까지 생성
- 5마리에서 복제 버튼 비활성화
- 드래그 후 쓰로잉 → 위치/속도 변화 확인
- 개별 숨김 → 해당 개체만 퇴장
- Math.random 고정 테스트에서 점프 5회 반복 유지
- 이후 수면 상태 진입 및 랜덤 체류 구조 확인
- 브라우저 콘솔/페이지 오류 0건
