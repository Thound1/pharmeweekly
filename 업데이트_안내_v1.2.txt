파메어스 무서버 주간보고 v1.2 업데이트 안내

기존 사이트 업데이트 파일
- index.html
- styles.css
- README.md

config.js는 기존 Google Client ID와 Spreadsheet ID가 들어 있으므로 덮어쓰지 않습니다.

업데이트 절차
1. 기존 config.js를 그대로 유지합니다.
2. 위 3개 파일을 GitHub 저장소 루트에 덮어씁니다.
3. Commit changes를 실행합니다.
4. GitHub Pages 배포 완료 후 사이트에서 Ctrl+F5를 누릅니다.
5. 화면 상단의 버전이 v1.2인지 확인합니다.

v1.2 주요 변경
- 파메스테틱 UI Guideline 색상 시스템 적용
- 헤더/툴바/보고서/담당자/프로젝트/작업 행의 상하 여백 압축
- 한 화면에서 담당자별 업무를 더 많이 볼 수 있도록 고밀도 레이아웃 적용
- 완료/예정일 입력칸과 우측 메뉴 버튼을 작업 행 전체 높이에 맞게 정렬
- 날짜 칸 너비 확대 및 경계선 정리
