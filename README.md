# 파메어스 플랫폼기획팀 주간보고 v1.2

GitHub Pages와 Google Sheets API를 사용하는 무서버형 주간보고 웹 화면입니다.
별도 애플리케이션 서버 없이 정적 HTML 화면에서 Google 스프레드시트의 데이터를 읽고 저장합니다.

## v1.2 변경사항

### 파메스테틱 UI 색상 시스템 적용

다음 디자인 시스템을 화면 전체에 적용했습니다.

- Primary: `#44599C`, `#1B1F27`
- Secondary: `#B6A685`
- Success: `#0095FF`
- Error: `#FC5555`
- Neutral: `#000000`, `#424242`, `#9E9E9E`, `#E0E0E0`, `#FFFFFF`

주요 CTA와 활성 탭은 Primary Blue, 제목과 주요 텍스트는 Dark Navy, 보조 구획은 Secondary Beige, 오류 상태는 Error Red를 사용합니다.

### 세로 스크롤 최소화

정보를 삭제하거나 글자를 지나치게 줄이지 않고, 계층별 여백과 행 높이를 재조정했습니다.

- 상단 헤더·툴바·화면 탭 높이 축소
- 보고서 제목 영역과 섹션 상하 여백 축소
- 담당자·프로젝트 간 간격 축소
- 프로젝트 헤더, 금주·차주 헤더, 작업 행 높이 압축
- 작업명·상세·날짜의 행간과 내부 여백 최적화
- 저높이 데스크톱 화면에서는 추가 고밀도 규칙 자동 적용
- 담당자/프로젝트/기간의 시각적 구분은 유지

### 완료/예정일 영역 정렬 수정

- 완료/예정일 너비를 88px로 확대
- 날짜 입력칸과 우측 `⋯` 버튼을 각각 완전한 셀 형태로 정렬
- `⋯` 버튼의 높이를 작업 행 전체에 맞춤
- 날짜 셀과 메뉴 셀 사이 경계선을 행 전체 높이로 표시
- 병합 작업명 행에서도 동일한 구조 유지

### 연속된 동일 작업명 병합 표시

같은 담당자·프로젝트·금주/차주 영역 안에서 동일한 작업명이 연속되면 사용자 화면에서는 하나의 세로 병합 셀처럼 표시합니다.

```text
QA F/U | 투입 전 환경 확인
       | 잔금 지출결의 준비
       | 그 외 질의사항 F/U
```

- 실제 Google Sheets 데이터는 행별로 유지됩니다.
- 상세와 완료/예정일은 각 행에서 따로 편집합니다.
- 특정 행을 다른 위치로 드래그하면 병합에서 자동 분리됩니다.

## 주요 기능

- 담당자 순서: 백인학 → 류재환 → 허미순 → 김환희
- 담당자별 프로젝트 및 작업 드래그앤드롭
- 금주·차주 제목 옆 `+ 작업`으로 빈 작업 즉시 생성
- 작업명 앞 `■` 자동 UI 표시
- 완료/예정일 자유 텍스트 입력
- 글자 크기 90%~250%
- 주차·월별·1~12월 전체 KPI 현황
- KPI 실적 화살표 1단위 증감, 직접 소수점 입력 가능
- 담당자·연도·월 기준 월간성과 `.xlsx` 출력
- 작성중/확정 상태값 및 인쇄 기능 제거

## 자동저장 방식

텍스트 입력 중에는 Google Sheets 저장 요청을 보내지 않습니다.

다음 시점에 한 번 저장합니다.

- 작업명·상세·완료/예정일 입력칸에서 포커스가 벗어날 때
- 프로젝트명 또는 KPI 비고 입력을 마치고 포커스가 벗어날 때
- KPI 실적 화살표를 누를 때
- 프로젝트·작업 추가 또는 삭제
- 드래그앤드롭으로 순서를 변경할 때
- 새 주차 생성 및 차주 업무 이월
- `지금 저장` 버튼을 누를 때

저장 완료 시 우측 하단에 다음 형식의 토스트를 표시합니다.

```text
[26-08-04 16:30:00 저장되었습니다.]
```

## 실행 모드

### DEMO 모드

`config.js`에서 `DEMO_MODE: true`로 설정하면 Google 연결 없이 브라우저 저장소로 기능을 확인할 수 있습니다.

### Google Sheets 실연동

`config.js`에 다음 값을 입력합니다.

```javascript
window.APP_CONFIG = {
  DEMO_MODE: false,
  GOOGLE_CLIENT_ID: "발급받은 OAuth 클라이언트 ID",
  SPREADSHEET_ID: "연결할 Google 스프레드시트 ID"
};
```

## GitHub Pages 업데이트

기존 사이트를 v1.2로 올릴 때 다음 파일을 교체합니다.

```text
index.html
styles.css
README.md
```

기존 Google OAuth Client ID와 Spreadsheet ID가 들어 있는 `config.js`는 덮어쓰지 않습니다.
커밋과 Pages 배포가 끝난 뒤 브라우저에서 `Ctrl + F5`를 눌러 캐시를 갱신합니다.
화면 상단에 `v1.2`가 표시되면 업데이트가 반영된 것입니다.

자세한 최초 배포 및 Google 연동 과정은 다음 문서를 확인하세요.

- `배포_및_Google연동_매뉴얼.html`
- `배포_및_Google연동_매뉴얼.md`
