# 파메어스 플랫폼기획팀 주간보고 v1.3

GitHub Pages와 Google Sheets API를 사용하는 무서버형 주간보고 웹 화면입니다. 별도 애플리케이션 서버 없이 정적 HTML 화면에서 Google 스프레드시트의 데이터를 읽고 저장합니다.

## v1.3 변경사항

### 로그인 계정 기억

상단의 `로그인 계정 기억`을 선택하면 마지막으로 연결한 Google 계정 이메일을 브라우저에 저장합니다.

- 다음 연결 시 해당 계정을 우선 사용해 계정 선택 단계를 줄입니다.
- Google 비밀번호와 액세스 토큰은 저장하지 않습니다.
- Google 세션이 만료되거나 권한이 철회되면 다시 연결해야 합니다.
- 체크를 해제하면 브라우저에 저장된 계정 이메일도 삭제됩니다.

### 색상 체계 재정리

- Main: `#1B1F27`
- Supporting Blue: `#44599C`
- Secondary Beige: `#B6A685`
- Success: `#0095FF`
- Error: `#FC5555`
- Neutral: `#000000`, `#424242`, `#9E9E9E`, `#E0E0E0`, `#FFFFFF`

상단 메뉴와 주요 버튼은 Dark Primary, 금주·선택 상태는 Blue, 차주·보조 정보는 Beige로 구분했습니다.

### 프로젝트 좌측 레일

프로젝트명을 업무 영역 위가 아니라 좌측 레일에 표시합니다.

- 프로젝트명 강조
- 프로젝트 드래그 버튼과 삭제 버튼을 좌측 레일에 배치
- 기존 프로젝트 상단 행 제거
- 같은 화면에서 더 많은 작업을 확인할 수 있도록 세로 공간 축소

### 작업 행 밀도 개선

- 실제 한 줄 내용은 한 줄 높이만 사용
- 자동 줄바꿈 또는 직접 줄바꿈이 생길 때만 높이 확장
- 작업명 앞 `■` 오브젝트를 셀의 세로 중앙에 배치
- 작업명·상세·완료/예정일을 세로 중앙 기준으로 정렬
- 연속된 동일 작업명의 병합 표시에서도 작업명을 묶음 중앙에 배치
- `3개 일정`과 같은 병합 건수 표기 제거
- 완료/예정일 플레이스홀더를 `00/00(월)`로 변경
- 금주·차주 기간 글자를 확대

### 삭제 처리 변경

`deleted` 상태값을 더 이상 사용하지 않습니다.

- 웹에서 작업·프로젝트·의사결정 항목을 삭제하면 메모리 배열에서도 즉시 제거됩니다.
- 저장할 때 Google Sheets 전체 데이터를 다시 작성하므로 삭제된 행은 시트에서도 실제로 사라집니다.
- v1.3 원본 양식에서는 `deleted` 열을 제거했습니다.
- 구버전 시트에 `deleted=Y` 행이 남아 있으면 최초 로드 시 제외되고, 다음 저장 때 시트에서 제거됩니다.

## 주요 기능

- 담당자 순서: 백인학 → 류재환 → 허미순 → 김환희
- 담당자별 프로젝트 및 작업 드래그앤드롭
- 금주·차주 제목 옆 `+ 작업`으로 빈 작업 즉시 생성
- 작업명 앞 `■` 자동 UI 표시
- 동일 작업명 연속 행 병합 표시
- 완료/예정일 자유 텍스트 입력
- 글자 크기 90%~250%
- 주차·월별·1~12월 전체 KPI 현황
- KPI 실적 화살표 1단위 증감, 직접 소수점 입력 가능
- 담당자·연도·월 기준 월간성과 `.xlsx` 출력

## 자동저장 방식

텍스트 입력 중에는 Google Sheets 저장 요청을 보내지 않습니다.

다음 시점에 한 번 저장합니다.

- 작업명·상세·완료/예정일 입력칸에서 포커스가 벗어날 때
- 프로젝트명 또는 KPI 비고 입력을 마치고 포커스가 벗어날 때
- KPI 실적 화살표를 누를 때
- 프로젝트·작업 추가 또는 삭제
- 드래그앤드롭으로 순서를 변경할 때
- 새 주차 생성 및 차주 업무 이월
- `지금 저장` 버튼을 누를 때

저장 완료 시 우측 하단에 다음 형식의 토스트를 표시합니다.

```text
[26-08-05 09:30:00 저장되었습니다.]
```

## 실행 모드

### DEMO 모드

`config.js`에서 `DEMO_MODE: true`로 설정하면 Google 연결 없이 브라우저 저장소로 기능을 확인할 수 있습니다.

### Google Sheets 실연동

```javascript
window.APP_CONFIG = {
  DEMO_MODE: false,
  GOOGLE_CLIENT_ID: "발급받은 OAuth 클라이언트 ID",
  SPREADSHEET_ID: "연결할 Google 스프레드시트 ID"
};
```

## GitHub Pages 업데이트

기존 v1.2 사이트를 v1.3으로 올릴 때 다음 파일을 교체합니다.

```text
index.html
app.js
styles.css
README.md
```

Google Sheets의 `deleted` 열까지 제거하려면 v1.3 원본 양식을 새 스프레드시트로 가져오거나, 기존 시트에서 `업무.deleted`, `KPI.deleted`, `의사결정.deleted` 열을 삭제합니다. 기존 열을 남겨도 앱은 구버전 데이터를 읽을 수 있으며, 다음 저장 시 v1.3 구조로 다시 작성합니다.

기존 Google OAuth Client ID와 Spreadsheet ID가 들어 있는 `config.js`는 덮어쓰지 않습니다. 커밋과 Pages 배포가 끝난 뒤 브라우저에서 `Ctrl + F5`를 눌러 캐시를 갱신합니다.
