# 파메어스 플랫폼기획팀 주간보고 v1.3.1

GitHub Pages와 Google Sheets API를 사용하는 무서버형 주간보고 웹 화면입니다. 별도 애플리케이션 서버 없이 정적 HTML에서 Google 스프레드시트의 업무·KPI·의사결정 데이터를 읽고 저장합니다.

## v1.3.1 최종 변경사항

### 프로젝트 좌측 레일 최종 압축

프로젝트 영역을 `드래그 │ 프로젝트명 / 삭제` 구조로 재배치했습니다.

- 프로젝트 드래그 버튼은 가장 왼쪽의 좁은 세로 영역에 배치
- 프로젝트명은 가운데 영역에서 세로 중앙 정렬
- 삭제 버튼은 프로젝트명 바로 아래 하단에 배치
- 좌측 프로젝트 레일 폭을 약 72~88px 범위로 축소
- 기존 상단 제어 행을 제거해 불필요한 세로·가로 공간 최소화
- 모바일에서는 드래그·프로젝트명·삭제가 한 줄로 전환

### 텍스트 수직 중앙 정렬

- 한 줄 작업명·상세·완료/예정일은 행 높이의 수직 중앙에 표시
- 작업명 앞 `■` 오브젝트와 드래그·메뉴 버튼도 수직 중앙 정렬
- 병합된 동일 작업명은 묶음 전체 높이의 중앙에 표시
- 여러 줄 내용은 실제 줄 수에 맞춰 높이가 확장되고 동일한 상하 패딩 유지
- 한 줄 일정은 한 줄 높이만 사용

### Google 연결 세션 유지

상단의 `세션 연결 유지`가 켜져 있으면 유효기간이 남은 Google 액세스 토큰을 **현재 브라우저 탭의 `sessionStorage`에만** 저장합니다.

- 페이지 새로고침 시 유효한 토큰이 있으면 로그인 버튼 없이 Google Sheets 연결 복원
- 토큰 만료 시 저장된 토큰을 자동 삭제하고 다시 연결하도록 안내
- 체크 해제 시 브라우저 세션에 저장된 토큰을 즉시 삭제
- 새 탭·새 브라우저·시크릿 창에서는 별도 세션으로 취급
- Google 비밀번호와 OAuth 클라이언트 시크릿은 저장하지 않음
- 액세스 토큰 자체의 유효기간이 끝난 뒤에는 Google 정책상 `Google 연결` 버튼을 다시 눌러야 함

`세션 연결 유지`는 기본적으로 켜져 있습니다.

### 기존 v1.3 기능 유지

- 메인 컬러 `#1B1F27`

## 자동저장 방식

텍스트를 입력하는 동안에는 Google Sheets 저장 요청을 보내지 않습니다.

다음 시점에 한 번 저장합니다.

- 작업명·상세·완료/예정일 입력칸에서 포커스가 벗어날 때
- 프로젝트명 또는 KPI 비고 입력을 마치고 포커스가 벗어날 때
- KPI 실적 화살표를 누를 때
- 프로젝트·작업 추가 또는 삭제
- 드래그앤드롭 순서 변경
- 새 주차 생성 및 차주 업무 이월
- `지금 저장` 버튼 클릭

저장 완료 시 다음 형식의 토스트를 표시합니다.

```text
[26-08-05 09:30:00 저장되었습니다.]
```

## 주요 기능

- 담당자 순서: 백인학 → 류재환 → 허미순 → 김환희
- 담당자별 프로젝트 및 작업 드래그앤드롭
- 금주·차주 제목 옆 `+ 작업`으로 빈 작업 즉시 생성
- 작업명 앞 `■` 자동 UI 표시
- 동일 작업명 연속 행 병합 표시 및 개별 행 분리 이동
- 주차·월별·1~12월 전체 KPI 현황
- KPI 실적 화살표 1단위 증감, 직접 소수점 입력 가능
- 담당자·연도·월 기준 월간성과 `.xlsx` 출력

## 실행 모드

### DEMO 모드

`config.js`에서 `DEMO_MODE: true`로 설정하면 Google 연결 없이 브라우저 저장소로 기능을 확인할 수 있습니다.

### Google Sheets 실연동

```javascript
window.APP_CONFIG = {
  DEMO_MODE: false,
  GOOGLE_CLIENT_ID: "발급받은 OAuth 클라이언트 ID",
  SPREADSHEET_ID: "연결할 Google 스프레드시트 ID"
};
```

## GitHub Pages 업데이트

기존 v1.3 사이트에서는 다음 파일을 교체합니다.

```text
index.html
app.js
styles.css
README.md
배포_및_Google연동_매뉴얼.html
배포_및_Google연동_매뉴얼.md
```

기존 Google OAuth Client ID와 Spreadsheet ID가 들어 있는 `config.js`는 덮어쓰지 않습니다. 커밋과 Pages 배포가 끝난 뒤 브라우저에서 `Ctrl + F5`를 눌러 캐시를 갱신하고 화면 상단의 `v1.3.1` 표시를 확인합니다.
