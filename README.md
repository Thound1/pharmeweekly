# 파메어스 플랫폼기획팀 주간보고 v1.1.3

GitHub Pages와 Google Sheets API를 사용하는 무서버형 주간보고 웹 화면입니다.
별도 애플리케이션 서버 없이 정적 HTML 화면에서 Google 스프레드시트의 데이터를 읽고 저장합니다.

## v1.1.3 변경사항

### 연속된 동일 작업명 병합 표시

같은 담당자·프로젝트·금주/차주 영역 안에서 동일한 작업명이 연속되면 사용자 화면에서는 하나의 세로 병합 셀처럼 표시합니다.

예시:

```text
QA F/U | 투입 전 환경 확인
       | 잔금 지출결의 준비
       | 그 외 질의사항 F/U
```

- 실제 Google Sheets의 업무 데이터는 기존처럼 행별로 유지됩니다.
- 상세 내용과 완료/예정일은 각 행에서 따로 편집합니다.
- 병합된 작업명 입력칸을 수정하면 묶인 행의 작업명이 함께 변경됩니다.
- 각 행의 드래그 핸들은 그대로 유지됩니다.
- 특정 행을 다른 위치로 드래그하면 연속성이 끊기면서 자동으로 독립 작업명 칸으로 분리됩니다.
- 모바일 화면에서는 편집 편의성을 위해 각 행의 작업명을 개별 표시합니다.

## 주요 기능

- 담당자 순서: 백인학 → 류재환 → 허미순 → 김환희
- 담당자별 프로젝트 및 작업 드래그앤드롭
- 금주·차주 제목 옆 `+ 작업`으로 빈 작업 즉시 생성
- 작업명 앞 `■` 자동 UI 표시
- 완료/예정일 자유 텍스트 입력
- 글자 크기 90%~250%
- 주차·월별·1~12월 전체 KPI 현황
- KPI 실적 화살표 1단위 증감, 직접 소수점 입력 가능
- 담당자·연도·월 기준 월간성과 `.xlsx` 출력
- 작성중/확정 상태값 및 인쇄 기능 제거

## 자동저장 방식

텍스트를 입력하는 동안에는 Google Sheets 저장 요청을 보내지 않습니다.

다음 시점에 한 번 저장합니다.

- 작업명·상세·완료/예정일 입력칸에서 포커스가 벗어날 때
- 프로젝트명 또는 KPI 비고 입력을 마치고 포커스가 벗어날 때
- KPI 실적 화살표를 누를 때
- 프로젝트·작업 추가 또는 삭제
- 드래그앤드롭으로 순서를 변경할 때
- 새 주차 생성 및 차주 업무 이월
- `지금 저장` 버튼을 누를 때

저장 완료 시 우측 하단에 다음 형식의 토스트를 표시합니다.

```text
[26-08-04 16:30:00 저장되었습니다.]
```

## 실행 모드

### DEMO 모드

`config.js`에서 `DEMO_MODE: true`로 설정하면 Google 연결 없이 브라우저 저장소로 기능을 확인할 수 있습니다.

### Google Sheets 실연동

`config.js`에 다음 값을 입력합니다.

```javascript
window.APP_CONFIG = {
  DEMO_MODE: false,
  GOOGLE_CLIENT_ID: "발급받은 OAuth 클라이언트 ID",
  SPREADSHEET_ID: "연결할 Google 스프레드시트 ID"
};
```

Google Sheets 원본 양식의 데이터 시트는 다음 구조입니다.

- 1행: HTML 사용 위치를 설명하는 한국어 안내
- 2행: 프로그램 연동용 영문 키
- 3행 이후: 실제 데이터

## GitHub Pages 업데이트

기존 사이트를 v1.1.3으로 올릴 때 다음 파일을 교체합니다.

```text
index.html
app.js
styles.css
README.md
```

기존 Google OAuth Client ID와 Spreadsheet ID가 들어 있는 `config.js`는 덮어쓰지 않습니다.
커밋과 Pages 배포가 끝난 뒤 브라우저에서 `Ctrl + F5`를 눌러 캐시를 갱신합니다.
화면 상단에 `v1.1.3`이 표시되면 업데이트가 반영된 것입니다.

자세한 최초 배포 및 Google 연동 과정은 다음 문서를 확인하세요.

- `배포_및_Google연동_매뉴얼.html`
- `배포_및_Google연동_매뉴얼.md`
