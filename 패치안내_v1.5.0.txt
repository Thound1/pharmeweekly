1. app.js 교체
2. styles.css 교체

4. assets/pamecon 폴더 전체 추가

config.js, seed-data.js, xlsx-export.js, Google Sheet는 변경하지 않습니다.

PAMECON 실행
- 좌상단 PE 로고를 약 2.2초 안에 5회 클릭하면 등장합니다.
- 이미 등장한 상태에서 다시 PE를 5회 클릭하면 점프 반응을 합니다.
- 파메콘 위치에서 마우스 우클릭하면 전용 메뉴가 뜹니다.
- '파메콘 숨기기'를 선택하면 퇴장 8프레임을 재생한 뒤 사라집니다.
- 다시 PE 5회 클릭 시 재등장합니다.

실제 프레임 애니메이션
- 등장: 8프레임
- 걷기: 6프레임
- 대기: 8프레임
- 앉기: 8프레임
- 점프: 8프레임
- 기지개: 8프레임
- 졸기: 8프레임
- 퇴장: 8프레임
총 62개의 투명 PNG 프레임을 사용합니다.

행동
- 화면 하단을 좌우로 걷습니다.
- 화면 가장자리에서는 자동으로 방향을 바꿉니다.
- 걷기 외에 대기/앉기/점프/기지개/졸기를 무작위로 수행합니다.
- 입력창(input/textarea/select/contenteditable)이 활성화되어 있으면 걷기를 멈추고 대기 동작으로 전환하여 업무 입력을 방해하지 않습니다.
- 왼쪽 이동은 동일 걷기 프레임을 CSS 좌우 반전하여 사용합니다.

업무 UI 영향 방지
- 파메콘 레이어는 pointer-events:none으로 일반 클릭을 가로채지 않습니다.
- 우클릭만 document 좌표로 캐릭터 영역을 감지하여 메뉴를 표시합니다.
- 기존 저장/동시편집/키보드 보호 로직은 수정하지 않았습니다.

검증
- Node.js app.js 문법 검사 통과
- Chromium 브라우저 테스트 통과
  · PE 5회 클릭 → 등장
  · 실제 PNG 프레임 변경 확인
  · 걷기 중 화면 좌우 이동 확인

  · 우클릭 메뉴 → 퇴장 → 숨김 확인
  · 숨김 후 PE 5회 → 재등장 확인
  · 콘솔/페이지 오류 0건
