주요 수정
1. 메인 입력칸 활성화 중 키 이벤트가 상위 화면으로 전달되지 않도록 차단
2. Space / Enter / Backspace / Delete가 페이지 스크롤·뒤로가기·외부 버튼 액션으로 처리되는 현상 방지
3. PageUp / PageDown / Home / End / 방향키가 포커스 유실 상태에서 페이지를 이동시키는 현상 방지
4. 예상치 못하게 입력 포커스가 body 등으로 빠진 경우 직전 편집칸으로 포커스를 복원
5. 복원 과정에서 Space, Enter, Backspace, Delete 및 일반 문자 입력을 해당 편집칸에 반영
6. 포커스 복원 시 페이지의 현재 스크롤 위치 유지
7. Tab / Escape / 마우스·터치로 입력칸 밖을 누르는 동작은 정상적인 포커스 이동으로 유지
8. 한글 IME 조합 중 이벤트는 건드리지 않음
9. 기존 v1.4.2의 동시편집/검증 저장 로직은 변경하지 않음
